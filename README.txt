GREENDEH - SITIO WEB

Archivos:
- index.html : sitio completo
- assets/logo.png : logo

PUBLICAR GRATIS (opciones):
1. GitHub Pages
2. Cloudflare Pages
3. Netlify

El sitio es estático: no requiere servidor ni base de datos.

PAGO CON TARJETA:
El botón actual solicita por WhatsApp un enlace de pago. Para cobrar tarjeta directamente en el sitio hay que conectar un proveedor como Mercado Pago o Stripe, que puede cobrar comisión por transacción.

CATÁLOGO:
Para agregar o cambiar productos, edita la lista "products" dentro de index.html.
